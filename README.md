# SiteLab India Quotation Generator

Vanilla HTML/CSS/JS version for GitHub Pages.

## Files
- `index.html`
- `style.css`
- `app.js`

## Domain change
The original AI/web-search **Check Price** feature has been removed. The app now has only:
- Domain name
- Domain Price / year

No Anthropic API is required.

## Storage
Saved quotations use browser `localStorage`, so they stay on the same browser/device. They are not synced to a server.

## GitHub Pages
Upload all three files to a repository and enable GitHub Pages from Settings → Pages → Deploy from branch.
